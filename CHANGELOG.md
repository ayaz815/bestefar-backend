# Changelog

Short, newest-first log of what's actually shipped in this repo, so a new session doesn't have to re-derive it from `git log`. Deploy status matters here since production (AWS EC2) only updates on an explicit `git pull && pm2 restart` — see `CLAUDE.md`.

- **2026-11-05** — Generator login (access-control Module 4c, not deployed): `POST /api/admin/login` (one admin from `.env`: `ADMIN_USERNAME`, `ADMIN_PASSWORD_HASH` from `scripts/hash-admin-password.js`), 7-day sessions, 5 failed tries = 15 min lock; `GET /api/admin/preview-key/:type/:id` for the generator Preview. With `ACCESS_ENFORCE=true` every create/edit/delete/upload/full-read route needs the login and public lists stay trimmed unless logged in. `trust proxy` set so the lockout sees the real visitor address.
- **2026-11-05** — Public show lists trimmed (access-control Module 4b, not deployed): with `ACCESS_ENFORCE=true`, `forms/get-all`, `image-quiz/get-all-image-quizzes`, `image-music/get-all-image-music-shows` and `audio-quiz/get-all-audio-quizzes` return only catalog fields (`utils/publicLists.js`), no questions/answers/file links. Off = unchanged (the generator archive still needs full lists until 4c).
- **2026-11-05** — Play keys (access-control Module 4a, not deployed): new read-only `/api/play/:type/:id` and `/api/play/:type/:id/pdf` for the players and catalog PDFs; those plus `audio-quiz/get-audio-quiz/:id` and the three `/pdf/:id` routes require a signed play key from bestefar.no once `ACCESS_ENFORCE=true` (and `ACCESS_TOKEN_SECRET`) are set in `.env`. Off by default. Generator routes untouched (Module 4c).
- **2026-11-04** — The three show lists (`forms/get-all`, `image-quiz/get-all-image-quizzes`, `image-music/get-all-image-music-shows`) now include `accessTier` (missing = restricted), for the website catalog (access-control Module 3).
- **2026-11-04** — Access control Module 1 (backend half, not deployed): `accessTier` field (restricted / registered / demo; missing = restricted) on AudioQuiz, ImageQuiz and ImageMusic, with `GET/PUT /api/access-tier/:type/:id`. Nothing enforces it yet. Branch `feature/access-tier`, stacked on `feature/publish-to-public-list`. Deploy: `git pull && pm2 restart bestefar-backend` on EC2.
- **2026-10-25** — Each S3 upload now gets a unique key (timestamp+random prefix) instead of the bare filename, so two uploads with the same name no longer overwrite each other (symptom: one melody played on every page). AudioQuiz `save-form` now only requires page + quizName so a new quiz can be saved with just its name. Added `test/audio-save.test.js` (`npm test`). **Deployed to EC2**.
- **2026-10-22** — Added BilderMusikk PDF (`GET /api/image-music/pdf/:id`): same question/answer sheets as BildeQuiz with the MusikkQuiz cover; on-screen text is the clue, melody name the answer. **Deployed to EC2**.
- **2026-10-15** — Added server-side AudioQuiz PDF generation (`GET /api/forms/pdf/:id`) for the website's "Skriv ut"/print feature - renders the same 3-page PDF (title, participant answer sheet, answer key) the generator's own "Export PDF" produces, ported to plain `React.createElement` at `backend/pdf/*.js`. Briefly deferred (built, reverted, then re-applied same day per the user) - **deployed to EC2**, confirmed live.
- **2026-10-12** — Fixed `quizInfo`/`quizMusician` silently never saving: `page` arrives from multipart form data as the string `"1"`, but the save handler compared it with `page === 1` (strict equality against a number), which was always false. Changed to `Number(page) === 1`. (`66cd3af`) — **deployed to EC2**.
- **2026-10-12** — Added `quizInfo`/`quizMusician` to the `Quiz` schema, the save-form handler, and the `get-all`/`get-by-id` responses, so the generator app and bestefar.no's catalog can read them back. (`78ed929`) — **deployed to EC2**.
- **2026-09-22** — Fixed audio quiz share links returning zero screens for old-model quizzes. (`1dc7bac`)
- **2026-09-17** — Opened CORS fully instead of whitelisting origins; before that, allowed any bestefar.no subdomain instead of exact-match origin. (`821a5d3`, `9004dec`)
- **2026-07-16** — Added the crossword quiz type/API. (`747255a`)
- **2026-06-07 → 2026-06-20** — Built out the ImageMusic quiz API (create, update, "about show" text, screen text). (`5b40b53` … `dd40621`)
